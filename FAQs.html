❓ Frequently Asked Questions (FAQ)

1. How do I load a new dataset?

First, download the dataset you wish to curate. Then, unzip it and copy the database file (.db) into the data/ subfolder of the curation tool. After that, click Load Dataset in the Control Panel and select the copied file. Once loaded, click Refresh Table to view the records.

2. What do the row colors in the table mean?

  • Grey: Pre-selected representative sequences (can be invalidated).
  • Green: Validated records (manually accepted).
  • Red: Excluded or invalid records (hidden by default; press “Show Invalid Records” to view).
  • White: Unselected records.

3. How can I view more columns in the table?

Use the Columns checkbox menu in the Control Panel to show or hide columns.

4. How do I apply or save changes?

Each row has a Submit button. You can also use Submit All on Page to apply all changes. Changes are stored in a change log.

5. Where can I find a record of my edits?

All edits are saved in logs/changes.log. Do not delete this file. Send it at the end of the process to:
📧 curation_tool@snsb.de and kuehbandner@snsb.de

6. Can I export the data?

Yes, use Export CSV to download visible and filtered data.

7. Something looks off—how can I reset filters?

Click Clear Filters in the Control Panel.

8. Is there a quick guide?

No dedicated quick guide button, but:

  • A detailed manual: user_manual_windows.html
  • Red question mark icons in the tool offer contextual help

9. What is BAGS and how is it used?

BAGS is a dynamic quality score. Click the red question mark icon near the BAGS column header for the grading scheme. bags_static shows a pre-computed, sortable version.

10. Troubleshooting common issues

  • Tool doesn’t start: Use start_tool.bat. Ensure data/ has the right .db files. Allow it to run via Windows Defender if prompted. Try renaming the project folder.
  • Browser doesn’t open: Open manually at http://localhost:3000
