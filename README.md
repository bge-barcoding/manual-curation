# manual-curation
[![DOI](https://zenodo.org/badge/986884387.svg)](https://doi.org/10.5281/zenodo.18877943)

Database files for the manual curation of BOLD records. If you just want the data visit our [user friendly version](https://bge-barcoding.github.io/manual-curation/).

Please read the [instructions](https://github.com/bge-barcoding/manual-curation/blob/main/_instructions/instructions.md) on how to use this repo, or head straight to the [data](https://github.com/bge-barcoding/manual-curation/tree/main/data) if you already know :)
